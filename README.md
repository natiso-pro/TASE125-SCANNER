# סורק מניות ת״א-125 – גרסת ענן (אנדרואיד + מחשב)

הסורק מתפרסם כאתר ב-GitHub Pages (חינם). שירות ב-GitHub מושך נתונים מ-Yahoo כל חצי שעה בשעות המסחר, ובטלפון מתקינים אותו כאפליקציה.
לא צריך Node.js, הרשאות מנהל או שרת משלך.

## התקנה חד-פעמית (כ-15 דקות)

1. **חשבון:** הירשם ב-github.com (חינם).
2. **מאגר חדש:** לחץ New repository. שם: `tase-scanner`. בחר **Public** (נדרש ל-Pages חינמי). סמן Add a README ואשר Create.
3. **העלאת הקבצים:** במאגר לחץ Add file → Upload files. פתח את ה-ZIP בתיקייה, וגרור פנימה את **כל** תוכנו, כולל התיקייה `.github`. לחץ Commit changes.
   אם התיקייה `.github` לא עלתה: Add file → Create new file, בשם הקובץ הקלד `.github/workflows/update.yml` והדבק את תוכן הקובץ `update.yml` מה-ZIP.
4. **הפעלת Pages:** Settings → Pages → תחת Source בחר **GitHub Actions**.
5. **הרצה ראשונה:** לשונית Actions → "עדכון נתונים ופרסום הסורק" → Run workflow. כשמופיע V ירוק, הכתובת מוכנה: `https://<שם המשתמש>.github.io/tase-scanner/`
6. **בטלפון:** פתח את הכתובת ב-Chrome → תפריט ⋮ → **התקן אפליקציה** (Install app). יופיע אייקון במסך הבית.

## עדכון גרסה של הסורק (בכל פעם שאעדכן לך את הקובץ)

במאגר: Add file → Upload files → גרור את `index.html` החדש (באותו שם) → Commit. תוך דקה-שתיים האתר והאפליקציה בטלפון מתעדכנים.
המחשב והטלפון משתמשים באותו קובץ, ולכן כל גרסה מתאימה לשניהם.

## הוספת מניה או תיקון סימול

ערוך את `tickers.txt` ישירות ב-GitHub (סמל העיפרון). לדוגמה: `טבע = TEVA.TA`. מניה חדשה נטענת עם היסטוריה של 5 שנים בריצה הבאה.
הקובץ `tickers_report.txt` באתר (`.../tickers_report.txt`) מראה מה נמצא ומה לא.

## מה לדעת

- **תדירות:** נתונים מתעדכנים כל חצי שעה בימים שני-שישי בשעות המסחר, ועוד פעם אחרי הסגירה. בכל יום מתרענן גם מכפיל הרווח והדוחות. האפליקציה הפתוחה בודקת נתונים חדשים כל 5 דקות.
- **לא קיים בענן:** רענון חי כל 5 שניות, מסחר אוטומטי וסימולציה חיה. אלה עובדים רק כשהסורק פתוח במחשב דרך `localhost:8765`.
- **התיק (סימולציה):** נשמר בכל מכשיר בנפרד. אפשר להעביר בין מכשירים בכפתור הגיבוי בסורק.
- **פרטיות:** האתר ציבורי: מי שיש לו את הכתובת רואה את הסורק. נתוני התיק לא עולים לענן.
- **אם Yahoo חוסם את GitHub:** שלב "משיכת נתונים" יסומן באדום ותקבל מייל. האתר ימשיך לעבוד עם הנתונים האחרונים. במקרה כזה שלח לי את הלוג.
- GitHub מכבה ריצות מתוזמנות אחרי 60 יום בלי פעילות במאגר. הוספתי שלב שאמור למנוע את זה. אם בכל זאת קרה, Actions → Enable workflow.
